# 🚀 JS Basics Starter: Перше практичне завдання

Ласкаво просимо до практичного завдання курсу **Frontend Learning Hub**!

---

## 📋 Завдання для виконання

1. Відкрийте файл [`src/greeting.js`](src/greeting.js).
2. **Завдання 1 (`greetUser`)**: Реалізуйте функцію, яка приймає ім'я студента та повертає шаблонний рядок:
   `"Привіт, [Ім'я]! Вітаємо у Frontend Camp."`
3. **Завдання 2 (`getCourseInfo`)**: Реалізуйте функцію, яка повертає об'єкт з полями:
   - `title`: `'Frontend Learning Hub'`
   - `year`: `2026`
   - `lessonsCount`: `11`

---

## 🛠️ Як перевірити код локально

1. Встановіть залежності проекту:
   ```bash
   npm install
   ```
2. Запустіть автотести:
   ```bash
   npm test
   ```
3. Для роботи в режимі спостереження (watch mode):
   ```bash
   npm run test:watch
   ```

---

## 🚀 Як здати роботу через GitHub

1. Зробіть комміт ваших змін:
   ```bash
   git add .
   git commit -m "feat: complete greeting and course info functions"
   ```
2. Відправте код у свій репозиторій на GitHub:
   ```bash
   git push origin main
   ```
3. Перейдіть у вкладку **Actions** вашого репозиторію на GitHub — там автоматично запуститься тестовий пайплайн.
4. Якщо всі тести пройшли — ви побачите зелену галочку **All checks have passed ✅**!
